# UniRetrieve  
### An AI-Powered Geospatial Framework for Secure Campus Asset Recovery

---

## 📌 Problem Statement

University campuses lack a centralized, automated system for managing lost and found items.  
Current methods such as physical notice boards or unverified social media posts are:

- Inefficient  
- Not real-time  
- Prone to fraudulent claims  
- Lacking intelligent search capabilities  

As a result, a high number of belongings remain unrecovered, creating inconvenience and security risks.

---

## 🎯 Objectives

### 1️⃣ Automated Classification
Implement Computer Vision models (CNN / YOLO) to:
- Automatically categorize uploaded item images  
- Extract features like color, type, and material  
- Reduce manual data entry  

### 2️⃣ Intelligent Matching
Develop a recommendation engine that:
- Cross-references "Lost" and "Found" entries  
- Uses metadata comparison + image similarity  
- Sends real-time matching alerts  

### 3️⃣ Secure Ownership Verification
Design a multi-step **Challenge–Response** verification module:
- Hidden ownership proofs  
- Student ID authentication  
- Fraud prevention mechanism  

### 4️⃣ Spatial Analysis
Integrate a geospatial mapping system to:
- Visualize "Loss Hotspots" on campus  
- Provide data-driven insights to administration  
- Improve campus security monitoring  

---

## 💡 Project Description

**UniRetrieve** is a Full-Stack SaaS platform built to modernize campus asset recovery systems.

The platform combines:

- 🌐 Web Engineering  
- 🤖 Computer Vision  
- 🗺️ Geospatial Analysis  
- 🔐 Secure Verification Systems  

### 🔎 How It Works

1. A finder uploads a photo of the item.
2. The AI model automatically extracts visual features and categorizes it.
3. The system compares it with existing "Lost" reports.
4. If a match is detected, the owner receives an instant notification.
5. Secure verification ensures only the rightful owner can claim the item.
6. Campus administrators can analyze geospatial data for security insights.
